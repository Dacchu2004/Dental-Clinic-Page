# BrightSmile Dental Clinic Landing Page Template

A premium, modern, and responsive landing page template designed specifically for dental clinics. This template features a clean aesthetic, service highlights, team introductions, patient testimonials, and a functional contact section.

## QUICK START:
1. **View the Site**: Open `BrightSmile Dental.html` in your web browser.
2. **Edit Content**: Right-click the `.jsx` files (like `hero.jsx` or `services-team.jsx`) and open them in VS Code or Notepad to edit the text and images.
3. **Change Styles**: Open `styles.css` or `sections.css` to modify colors, fonts, and layouts.
4. **Deploy for Free**: To put your site online, upload this entire folder to [Vercel.com](https://vercel.com) or [Netlify.com](https://netlify.com).
   - *Note: For best results when deploying, rename `BrightSmile Dental.html` to `index.html`.*

## Features:
- **Modern Design**: High-end look with smooth animations and professional typography.
- **Responsive Layout**: Optimized for desktops, tablets, and mobile phones.
- **Easy Customization**: Built with modular JSX components and clean CSS.
- **Interactive Elements**: Includes a "Before & After" gallery, insurance info, and contact forms.

## Technology Stack:
- HTML5 & Vanilla CSS
- React (via Babel Standalone)
- Google Fonts (Inter, Fraunces, Manrope)
